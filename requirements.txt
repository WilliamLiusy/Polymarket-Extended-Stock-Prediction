# ## numpy/pandas/scipy 为什么必须钉死
#
# pyqlib 0.9.7 的依赖只写了 `numpy`（无上限）和 `pandas>=0.24`，于是 pip 会装上
# numpy 2.x + pandas 3.x —— 这两个版本在 qlib 0.9.7 发布时都还不存在。
# 实测踩过的坑：
#   * 只降 numpy/pandas 而不管 scipy → scipy 1.18 要求 numpy>=2.0，
#     报 `AttributeError: module 'numpy' has no attribute 'long'`（scipy/sparse/_sputils.py），
#     连 `import lightgbm` 都挂。
#   * contourpy / cvxpy 的新版也各自要求 numpy>=2。
# 所以下面这一组是**必须整组一致**的，别单独升某一个。
